# Capa-do-meu-album
## A capa

![Capa do álbum](capa-do-meu-album.png)

| Elemento | Escolha |
|---|---|
| Título do álbum | Só Sei Que Nada Sei |
| Nome artístico | GUESS |
| Imagem central | Um personagem vestido de vermelho, sentado em uma cadeira, em uma posição de reflexão. |
| Paleta de cores | Vermelho, preto e dourado. |
| Fundo | Um cenário escuro com textura envelhecida e detalhes em vermelho, criando contraste com a iluminação dourada no centro. |
| Conceito | A imagem transmite uma ideia de reflexão sobre a vida, mostrando que conhecer a si mesmo também significa reconhecer que ainda temos muito a aprender. |
| Selo | RACIONAL |
